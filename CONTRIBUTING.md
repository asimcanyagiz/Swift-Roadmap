# Swift Roadmap'e Katkı

Swift Roadmap, Swift öğrenenlere açık ve anlaşılır Türkçe içerik sunmayı amaçlar. İçerik düzeltmeleri, daha iyi örnekler ve eksik konular için katkılar memnuniyetle karşılanır.

## Başlamadan önce

1. Benzer bir issue veya pull request olup olmadığını kontrol edin.
2. Büyük bir yeni konu eklemeden önce kısa bir issue açarak kapsamı açıklayın.
3. Tek pull request içinde mümkün olduğunca tek konuya odaklanın.

## İçerik ilkeleri

- Açıklamaları yeni öğrenen bir geliştiricinin anlayabileceği şekilde yazın.
- Kod örneklerini küçük, çalıştırılabilir ve konuya odaklı tutun.
- Güncel Swift sözdizimini kullanın; sürüme bağlı davranış varsa sürümü belirtin.
- Başka kaynaklardan metin kopyalamayın. Kaynak kullandıysanız bağlantısını ekleyin.
- Kişisel veri, erişim anahtarı veya gizli proje kodu eklemeyin.

## Pull request kontrol listesi

- [ ] Markdown bağlantıları doğru dosyaya veya güvenilir kaynağa gidiyor.
- [ ] Kod bloklarının dil etiketi bulunuyor (`swift`, `bash` gibi).
- [ ] Başlık yapısı okunabilir ve mevcut içerikle tutarlı.
- [ ] Yazım ve teknik terimler kontrol edildi.
- [ ] Değişiklik yalnızca açıklanan kapsamı içeriyor.

## Bildirim

Küçük bir yazım veya bağlantı hatası için doğrudan pull request açabilirsiniz. Teknik doğruluk veya kapsam konusunda emin değilseniz issue açmanız yeterlidir.
